# Midjourney queue

One line per asset. Run each prompt in Midjourney (V7+/V8, paid plan), pick the best of the four, upscale,
and save the PNG as `art/inbox/midjourney/<key>.png` (the key with `/` written as `__`, e.g.
`monsters__card_shark.png`). Then `npm run art:import`. Lines are appended by the pipeline; a line whose file has
landed is marked DONE on import. `--sref` ids come from art/style/refs.json once the style sheet is approved.
